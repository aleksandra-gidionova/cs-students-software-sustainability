# Software Sustainability from the Student Perspective – Replication Package

Replication package for the paper *"Software Sustainability from the Student Perspective: Dimensions, Barriers and Learning Expectations"* (Gidionova and Jordine, Stuttgart Media University).

## Contents

### Focus group workbook
`focus_group_replication_data.xlsx`

| Sheet | Content |
|---|---|
| `Protocol` | Session facts and the prompts for each phase |
| `Participants` | Aggregated demographics of the six participants |
| `Understanding` | Pre-session self-assessment of understanding per dimension |
| `Rankings` | Individual rankings of the five dimensions and resulting scores |
| `Cards` | All Start/Stop/Continue cards verbatim and the named stakeholders |
| `Discussion` | Verbatim transcript excerpts, linked to the cards they elaborate |
| `Coding` | Code, theme and informed survey items for every card and excerpt |
| `Item_Sources` | For each option of survey items Q11 and Q13–Q15, the themes and sources that informed it |

### Survey workbook
`survey_replication_data.xlsx`

| Sheet | Content |
|---|---|
| `Data_Coded` | One row per respondent, numerically coded; all result sheets compute from this sheet |
| `Codebook` | Every variable with question ID, label and coding |
| `Questionnaire` | Questions Q1–Q15 in English and German, with options and display conditions |
| `Open_Text` | Open-text answers in German with the authors' English translation |
| `Demographics` | Aggregated counts for variables withheld at respondent level |
| `RQ1_Dimensions`, `RQ2_Barriers`, `RQ3_Learning` | Result tables per research question |
